# 40 Days of JavaScript

A focused pass through the JavaScript fundamentals, following [tapaScript's 40 Days of JavaScript](https://github.com/tapascript/40-days-of-javascript) by Tapas Adhikary, logged here day by day.

## Why

I've shipped production interfaces for years with Webflow, React and GSAP. This is about going deeper than everyday usage: the execution context, scope and closures, `this`, prototypes and the event loop. That depth makes the difference when a problem gets harder: tricky async flows, performance issues, architecture decisions and technical challenges where intuition isn't enough.

The goal is to understand *why* the language behaves the way it does, not just how to use it.
